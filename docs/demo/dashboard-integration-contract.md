# CareTrust dashboard integration contract

`artifacts/validation/dashboard-contract.json` is the stable
`caretrust.dashboard-contract.v1` payload for the dashboard and any synthetic
reference client. It is generated by:

```powershell
.\.venv\Scripts\python.exe scripts\build_dashboard_contract.py
```

The contract consumes only three source truths: `build_synthetic_case_bundle()`,
the retained synthetic compiler fixtures, and the Core v0.1 bridge validation
artifact. It does not make authorization decisions, maintain UI-only state, or
call a network service.

Its views cover the case overview, care team, canonical permission decisions,
history, application registry/proposals, reference-client receipts, evidence,
AI review, accountable correction, standards messages/mappings/gaps, and
revocation effects. Every material row includes canonical references, a source
hash, an evidence-status label, and non-claim boundary text.

Reference-client receipt rows deliberately include only their minimum-data
disclosure projection. They omit raw documents, source pages, extraction output,
raw packets, unrelated claims, supporting authority chains, and clinical-holder
payloads.

The AI review view shows retained synthetic candidate quote → validated bounded
value → draft-binding lineage and makes the separate human-review requirement
explicit. It does not claim a live Bedrock invocation. The correction timeline
is an accountable review of a synthetic uploaded-document draft; it does not
establish legal authority or current clinical truth.

Core message rows inherit the Core artifact's `executed_local` evidence status;
mapping rows remain `mapped_only`. No live OAuth/OIDC, application registration, EHR,
HIE, registry, federation, or model deployment is claimed.
